## Monochrome Drift — Ambient Screensaver

Designed for calm focus and visual stillness, **Monochrome Drift** transforms your screen into a quiet, distraction-free canvas. Built around a pure black-and-white palette, it removes unnecessary clutter, bright colors, and visual noise to create a soothing backdrop for your workspace or room.

### ✨ Key Features

- **Distraction-Free Visuals:** Minimalist monochromatic motion designed to stay gentle on the eyes without demanding your attention.
- **Always-Awake Mode:** Uses the browser's Screen Wake Lock API to keep your display active continuously without triggering your device's lock screen or sleep timer.
- **Zero Clutter:** No ads, menus, or pop-ups interrupting the flow—just pure, uninterrupted ambient motion.

### 🚀 Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```
2. **Navigate to the project folder:**
   ```bash
   cd stand-by-focus
   ```
3. **Run the project:**
   Open `index.html` directly in any modern web browser (Chrome, Edge, Safari, or Firefox).
